# Expense Tracker

A beginner-friendly Python expense tracker built to practice core Python concepts.

## Features

- Add expenses
- View all expenses
- Calculate total expenses
- Calculate spending by category
- Search expenses
- Delete expenses

## Concepts Practiced

- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
- Dictionary methods

## Future Improvements

- Input validation
- Exception handling
- JSON file storage
- Modules
- Unit testing
